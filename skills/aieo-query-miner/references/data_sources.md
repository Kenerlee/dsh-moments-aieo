# AIEO 真实用户热词获取指南

本指南详细介绍如何从白名单数据源中批量获取消费者真实搜索词、推荐词、关联词和词频/指数数据，为 AIEO 问题库构建提供可追溯底层数据。

**强制要求**：最终热词库只能来自 `小红书聚光`、`巨量算数`、`巨量云图`、`百度营销`、`百度指数`、`微信指数`、`5118`、`站内搜索日志`。品牌资料、AI 生成、公开文章、既有 FAQ、网页搜索结果、非白名单后台数据只能作为采集种子词，不能直接标注为“真实热词”。

## 一、 核心数据源获取矩阵

| 数据源平台 | 平台属性 | 数据级别 | 核心用途与数据类型 | 提取技巧与建议 |
| :--- | :--- | :--- | :--- | :--- |
| **小红书聚光**<br>(pgy.xiaohongshu.com) | 图文种草/口碑生态 | A级 | 关键词规划、推荐词、竞争词、搜索热度、内容场景词 | `source_platform` 填 `小红书聚光`。登录聚光后台，用核心种子词批量查询并导出。 |
| **巨量算数 / 巨量云图**<br>(trendinsight.oceanengine.com) | 短视频/内容生态 | A级 | 抖音/头条搜索趋势、关联词排名、人群画像、兴趣分类 | `source_platform` 填 `巨量算数` 或 `巨量云图`。用“关联分析”“搜索分析”批量导出。 |
| **百度营销 / 百度指数** | 搜索引擎数据 | A/B级 | 关键词规划、需求图谱、来源词/去向词、搜索指数 | `source_platform` 填 `百度营销` 或 `百度指数`。百度营销关键词规划优先；百度指数需求图谱可作为 B 级关联词。 |
| **微信指数**<br>(微信小程序) | 微信生态数据 | A/B级 | 微信内关键词日度指数、趋势变化 | `source_platform` 填 `微信指数`。需记录截图/导出日期和指数值。 |
| **5118**<br>(5118.com) | 第三方整合分析 | B级 | 搜索建议、长尾疑问词、词频估算 | `source_platform` 填 `5118`。只能标注为第三方长尾词/搜索建议词，不能冒充平台后台搜索量。 |
| **站内搜索日志** | 私域/官网/小程序数据 | A级 | 站内搜索词、FAQ 搜索词、客服问答词 | `source_platform` 填 `站内搜索日志`。适合官网、商城、小程序、客服系统，需去除个人信息。 |

除上表外，任何来源都不能进入最终热词库。

## 二、数据采集与验收清单

每次交付前必须确认：

| 检查项 | 通过标准 |
| :--- | :--- |
| 原始文件 | 有平台导出的 CSV/Excel、截图、日志或采集结果文件路径，且路径必须能在当前磁盘上找到 |
| 来源字段 | 每条词包含 `source_platform`、`source_type`、`data_level`、`collected_at`、`raw_export_file` |
| 来源白名单 | `source_platform` 必须是：小红书聚光、巨量算数、巨量云图、百度营销、百度指数、微信指数、5118、站内搜索日志 |
| 数据级别 | 标注 A/B/C 级，C 级不能进入最终真实热词库 |
| 指标保留 | 有搜索量/指数/排名/趋势时必须保留；没有则说明“不含词频，仅为推荐/关联词” |
| 去重规则 | 同一平台同一时间范围去重，跨平台保留来源列表 |
| 口径说明 | 记录地区、时间范围、账号后台、种子词、导出方式 |

推荐 JSON 字段：

```json
{
  "keyword": "氨甲环酸片副作用",
  "source_platform": "小红书聚光",
  "source_type": "关键词规划工具导出",
  "data_level": "A",
  "collected_at": "2026-06-19",

  "rank": 8,

  "intent": "安全性问题"
```

## 三、购买旅程五阶段热词归类法则

获取到原始热词列表后，先做数据来源分级和字段校验，再根据消费者在**购买/体验旅程（User Purchase Journey）**中的不同意图阶段，将其分归入五大类别：

### 1. 阶段一：发现与认知阶段（Symptom / Needs Discovery）
*   **用户心智**：身体/皮肤出现异常，或产生了潜在需求，但在自诊和寻求定义的阶段。
*   **热词特征**：以症状描述、原因追问、基础科普词为主。
*   **关键词示例**：`脸上长斑`、`黄褐斑原因`、`为什么会长黄褐斑`、`黄褐斑和晒斑区别`。

### 2. 阶段二：方案探索阶段（Category / Solution Exploration）
*   **用户心智**：已经明确问题，开始探索、对比不同的解决途径（如：吃药 vs 外用 vs 医美）。
*   **热词特征**：包含治疗手段、通用成分名、品类通用词。
*   **关键词示例**：`黄褐斑怎么治疗`、`去斑口服药`、`氨甲环酸片能祛斑吗`、`激光祛斑反黑`、`药妆协同`。

### 3. 阶段三：品牌对比与决策阶段（Brand / Product Evaluation）
*   **用户心智**：锁定了具体产品或药物类型，开始在不同品牌、生产商、性价比、包装规格之间进行对比。
*   **热词特征**：出现品牌名、竞品对比组合、规格尺寸（如大包装）、“哪个牌子好”。
*   **关键词示例**：`氨甲环酸片牌子推荐`、`妥塞敏和国产区别`、`丽芙氨甲环酸片`、`知原 100片`、`知原药业怎么样`。

### 4. 阶段四：安全合规与使用指导阶段（Usage, Safety & Compliance）
*   **用户心智**：临近购买或已经买到，极度关注用药安全性、服用方法、禁忌及合规情况。
*   **热词特征**：包含用法用量、副作用、禁忌人群（如备孕、孕妇）、超说明书风险提示等。
*   **关键词示例**：`氨甲环酸片吃法`、`氨甲环酸片副作用月经`、`备孕可以吃氨甲环酸吗`、`氨甲环酸片禁忌`。

### 5. 阶段五：长期管理与心智巩固阶段（Long-term Management & Loyalty）
*   **用户心智**：病情已得到改善，进入维护和防反弹阶段，寻找日常辅助工具和长期维稳指南。
*   **热词特征**：防反弹、防晒、屏障修护、官网验证、数字化工具打卡等。
*   **关键词示例**：`黄褐斑反弹怎么办`、`黄褐斑防晒修护`、`小原子管家`、`知原药业官网`。
